# Моё расписание

Личное приложение для macOS 13 и новее: импорт календаря `.ics`, просмотр
недель и домашние задания к конкретным парам. Требуется Xcode 15 или новее.
Сторонних зависимостей нет.

## Запуск на Mac

1. Скачайте этот репозиторий на Mac (Code → Download ZIP на GitHub либо `git clone`).
2. Откройте `Package.swift` в Xcode.
3. Выберите схему **Schedule**, устройство **My Mac** и нажмите **⌘R**.
4. Нажмите **Импорт .ics** и выберите файл расписания.
5. Выберите пару, напишите задание и нажмите **Сохранить** или **⌘S**
   перед переключением на другую пару.

Альтернативный запуск из Terminal в папке проекта:

```sh
swift run Schedule
```

## Проверка первой версии

- Импортируйте выгрузку группы `15.27Д-ПИ02/25б`: предоставленный пример
  содержит 85 занятий с 12 октября по 11 ноября 2026 года.
- После импорта приложение откроет неделю первого занятия. Проверьте
  12 октября: 08:30 — облачные технологии, 10:10 — теория вероятностей,
  11:50 — дискретная математика. Время отображается по Москве.
- Перейдите на следующую неделю, выберите пару, запишите и сохраните задание.
- Закройте приложение и запустите снова: расписание и задание должны сохраниться.
- Повторно импортируйте тот же файл: количество занятий не должно увеличиться,
  сохранённое задание должно остаться.
- Попробуйте импортировать некорректный файл: приложение должно показать ошибку,
  сохранив прежние данные.

## Хранение и ограничения

Данные сохраняются локально в
`~/Library/Application Support/PersonalSchedule/schedule.json`.
Файл содержит и расписание, и домашние задания; его можно копировать для резервного хранения.
Личные данные не отправляются на сервер и не входят в репозиторий.

Импорт объединяет занятия по `UID`. Старые занятия не удаляются, даже если
их нет в новой выгрузке. Автоматическое определение отмен и переносов пока
не реализовано: стабильность UID при переносе ещё не проверена.
Поддерживаются отдельные события с точным временем; повторяющиеся события
RRULE, исключения RECURRENCE-ID и события на весь день отклоняются целиком,
чтобы не импортировать неполное расписание.

Автоматическая загрузка по ссылке, создание своих занятий и синхронизация
с iPhone — следующие этапы. Сейчас используется ручной импорт `.ics`.

В облачной Linux-среде нет Swift/Xcode: сборка и проверка интерфейса
на Mac ещё не выполнены. Проверки выше нужно выполнить в Xcode.
